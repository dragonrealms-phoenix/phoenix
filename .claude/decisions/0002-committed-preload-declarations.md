# The preload API's type declarations are generated and committed

`electron/preload/index.d.ts` is generated by `yarn build:preload` and committed.
Main and renderer get the `window.api` contract from it, through their tsconfig `include`, instead of importing preload source.
This lets main and renderer typecheck in the editor, lint and CI without building preload first.
It also keeps preload source out of the renderer bundle, since preload compiles separately to CommonJS for the sandboxed renderer.

## Consequences

- After changing `electron/preload/index.ts`, regenerate and commit `index.d.ts`; a stale copy silently hides new channels from main and renderer.
- Never edit `index.d.ts` by hand.
- The generated file also declares `common/...` modules, which is why a bare `common/...` import type-checks in main.
